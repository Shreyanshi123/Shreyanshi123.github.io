# Shreyanshi Mishra: Portfolio

A static portfolio site. No build step.

## Deploy to GitHub Pages

1. In the repository named `Shreyanshi123.github.io`, delete the old `index.html`, `style.css`, `script.js` and `assets` folder.
2. Upload the new `index.html`, `style.css`, `data.js`, `script.js` and the whole `assets` folder to the root of the repository, on the `main` branch.
3. In Settings, then Pages, set the source to the `main` branch and the `/ (root)` folder.
4. Open https://shreyanshi123.github.io after a minute or two. Refresh with Ctrl+Shift+R if you still see the old site.

## Editing

- **Content:** open `data.js`. Your experience, projects, skills and the rotating hero words are all there. Edit the text, save, and the page, the search box and the skill links all update.
- **Repository links:** in `data.js`, change `repo: null` to the repository URL for that project.
- **Hero and About text:** edit `index.html`.
- **Colors:** change the variables at the top of `style.css`.
- **Résumé:** replace `assets/Shreyanshi_Mishra_Resume.pdf` with your latest PDF, keeping the same file name.
